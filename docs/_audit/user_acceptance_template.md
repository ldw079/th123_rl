# R19 用户验收包模板（≤1 页）

## 1. 变更摘要
- 任务/变更 ID：
- 一句话说明（用户视角，不用内部术语）：
- 改动范围（哪些行为/界面/对局体验会变）：

## 2. 证据（用户可核）
- 回放片段/录像路径（可直接打开）：
- 数据/日志路径（可选）：
- 审计/门禁结论（仅供参考，不替代用户判断）：

## 3. 我无法独立判断的点（必填）
- （例如：连段自然度、操作手感、"是否像人类"、"该策略是否符合你的对战直觉"）

## 4. 具体 yes/no 问题
1. 你能看到的行为改善是？是 / 否 / 不确定（说明）
2. 哪些操作/连段仍做不到？（列举，可附回放时间点）
3. 是否同意保留此变更？同意 / 不同意（说明）

## 5. 结论
- 用户 PASS / FAIL（签名/日期）；Lead 自评仅初判，用户否决即 FAIL。
