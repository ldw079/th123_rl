## 1. DoD 错位（完成定义）
- 旧 DoD＝"窗完成/门禁绿/env 生效"，**不等于行为改善**；用户三观察（主动性/逃压/空间感知）
  未映射为可测指标与门限 → "完成"与"有效"脱节。
- 修复：DoD 必须含 **用户观察→指标→门限→样本量→观察期**；窗验收=行为指标达阈值（非仅 PASS）。

## 2. 度量缺失
- 331 断言→7 行为（约 2%）；行为测试多为布局/存在性；训练面板看熵/KL/胜率，
  无 combo 尝试/完成、空挥成本、空间事件反应。
- 修复：指标映射表（§10）+ 日更；行为仪表与门禁分离（仪表只诊断，门禁只约束）。

## 3. 同源自证（本周期最大方法论漏洞）
- 根因链：executor 门语义 bug → 训练/回放/QC 共用同一实现 → 现象一致 → "验证通过"；
  宽松判据（dmg>0/acts≥2）进一步掩盖。
- 修复（R15 扩展）：独立真值 **≥2 来源**（手动输入基准/留出场景/独立工具/盲抽审计）；
  QC 不得由被检对象自身聚合；replay 判据必须行为（combo 完成/伤害阈值）。

## 4. 变更管理
- 多变量同窗（buffer+C1 同日）、无预注册、无样本量/停止规则、无回滚演练 → 不可归因。
- C1 无效当日切 C2；D1/D2 设计反复；B 窗多次改期。
- 修复（R17）：预注册模板；**单变量窗 + 冻结评估夹具**；停止规则（样本/时间/指标）；
  回滚演练入窗 DoD。

## 5. 架构先行缺失
- 制品/BC 多格式、98 env、gate 单体、9 迁移脚本、Episode schema 漂移 → 每次改动都在还债。
- 修复（R16/R17）：新机制先评审 **registry/config/schema/gate 规则表**；一次迁移设计；
  禁一次性 hack；过渡件登记移除计划。

## 6. WIP/排期
- 并行窗过多、重启频繁、睡眠/静默停机 30h+ → 训练时段碎片化、A/B 失效。
- 修复：WIP≤2 主线；窗合并规则（同变量类）；停机账/睡眠记录入日报；重启预算（每 48h≤2 次）。

## 7. 评估基准
- eval_matrix 10-02、人测 10-18 旧模型 → 无法量化"超人"进度。
- 修复：冻结评估夹具（固定对手/种子/局面集，版本化）；每周基准 + 人测复测；
  指标版本化（旧矩阵标"映射前/旧代"）。

## 8. 复盘制度
- 无 postmortem/决策日志/周复盘；事故教训靠口口相传。
- 修复：postmortem 模板（事件/证据/根因/行动/owner/期限）；决策日志（每次窗/架构决策）；
  每周行为+架构复盘（30min）。

## 9. R17 制度修订（12 条；已转录 METHODOLOGY §0 + PARALLEL_WORKFLOW §R17；auditor 附章待并入）
1. **预注册**：每个变更窗提交 1 页：假设/单变量/指标/样本量/停止规则/回滚/DoD。
2. **单变量窗 + 冻结评估夹具**：窗内只改 1 变量；评估用版本化夹具（种子/对手/局面集）。
3. **DoD 行为化**：用户观察→映射表指标；窗验收必须含行为阈值（≥N 局/≥X%）。
4. **独立真值≥2**：行为/数据验证须 2 个独立来源；禁止同源 QC 自证（R15 扩展）。
5. **架构先行**：新机制先经 registry/config/schema/gate 规则表评审；禁止旁路/一次性迁移。
6. **WIP≤2 主线**；窗/重启预算；睡眠/停机账日更。
7. **周复盘 + postmortem + 决策日志**；每次 P0/P1 事故 24h 内出 postmortem。
8. **反债**：过渡 env/兼容层登记到期日与移除 Wave；超期门禁红。

# 附章（审计侧）：为何漏检/为何指标没靶（auditor，2026-10-25 夜）

> 详版：`docs/_audit/methodology_retro_audit_20261026.md`（本附章为可合并摘要；R15：只写文档、不改代码）。
> 结论：门禁全绿/任务完成≠用户观察改善，根因是**验收范式**——缺预注册主行为指标、独立真值、frozen eval、事故闭环。

## A1 同源自证为何漏到 R15
- 事实：BC 锚采集/复验同一 `macro_executor`、QC 由同 npz 聚合；门禁 331 chk 仅 7 纯行为、76 纯 `src()`；Gen-1 双零初始化等"门禁绿但未学习"先例。
- 根因：审计默认"测试存在/源码含锚"=通过；无独立真值定义；R15 前无成文红线；审计在实现后介入。
- 修正：R15 升验收前提（协议 §四）；独立真值≥2；变异须行为红；新门禁先审后入。

## A2 行为变更缺预注册/样本门
- 事实：C1/C2/A′ 小样本先判、窗按小时非 commit/restart、多变更叠加不可归因。
- 修正：实验预注册单（假设/单变量/主指标/固定窗/最小样本/CI/停止/回滚）**窗前列签**；样本不足=不判；未预注册只作探索性。

## A3 north-star 行为指标缺失
- 事实：长期以门禁数/任务完成验收；用户三观察未映射；策略仍远弹被动/逼近低/挂角升。
- 修正：Behavior Metrics Registry（用户观察→主指标/分母/窗/CI/反例帧）；门禁数不得作行为验收；24–48h 用户可读摘要。

## A4 评估基准缺失
- 事实：plain/fleet 多代、池旧快照回退、BC 混代际、无 frozen eval；同一策略数字跨期不可比。
- 修正：Frozen Eval（固定模型/对手池/种子/帧）+ C1 registry 前置；无基线不判改善。

## A5 复盘闭环
- 事实：19:59 全灭/唤醒/`_buf_cnt`/锚泄漏等无统一 postmortem；同类根因反复。
- 修正：Postmortem+Decision Log（根因/动作/owner/deadline/验证/关闭）；P0/P1 未闭环不进 W4/Gen-2 大迁移。

## A6 审计流程改造（建议并入 R17）
1) 设计阶段先审 AC 合同；独立真值/north-star/frozen eval 方案随设计提交。
2) 实现阶段只收行为/契约证据；R15 红线；纯串断言不计 PASS。
3) 窗阶段预注册单+commit/restart 切窗+样本门；样本不足=不判。
4) 部署阶段备份/原子/回滚/三面 hash+frozen eval 前后对比。
5) 复盘阶段 postmortem/decision log 闭环；同类根因→新 AC。
6) 报告规范：主指标/样本/CI/失败帧/归因边界/未证实标注；禁"门禁全绿=行为改善"。

## A7 建议追加的 R17 条款（审计侧）
- **R17-9（审计预注册检查表+二次独立复核）**：审计报告须自检"口径/样本/独立真值/未证实标注"；关键结论（P0/迁移/安全）须二次独立复核；审计自身误判（34min 先判/旧口径/锚泄漏初查滞后）记入 R17 教训栏。
- **R17-10（north-star 门）**：行为类变更任务必须先绑定 Behavior Metrics Registry 主指标；未绑定不得宣称效果；门禁数/任务完成不进行为验收。
- **R17-11（frozen eval 门）**：API/行为/迁移变更前须有 frozen eval 基线（模型/对手/种子/帧）；无基线视为未通过。
- **R17-12（事故闭环门）**：P0/P1 未完成 postmortem+decision log（含验证证据）不得进入架构大迁移（W4/Gen-2）；同类根因复发→升级 AC。
- 与现有 §9 R17 草案 8 条合并；R15 中"独立真值≥2"与本附章一致，无需重复。
