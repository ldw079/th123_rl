# 深度分析：现有架构能否完成所有人类高手操作（择/打乱动等）

> 日期: 2026-10-04 · 依据: 钢琴男攻略集四部（综合/立回压制/防御对策/游戏系统）反编译全文提取的 167 项技法分类 × 现有架构四层核验
> 方法: 每项技法按四层评估——L1 执行表达（宏库能否发出）/ L2 感知可见（特征能否看见）/ L3 反应时序（决策节奏能否赶上）/ L4 学习信号（奖励与对手建模能否学会）
> 结论速览: **不能完成"所有"高手操作。当前架构是"立回+连段+固定压制链"型选手（执行类覆盖约五到六成）; 对"择"与"打乱动"这两族得分核心存在架构性缺口——执行缺件、感知缺维、时序缺墙，三者都不是调参可解决的。**

## 2. 逐族映射结论

### 2.1 立回（25 项）—— **大体可行，粒度粗** ✅◐
- 高度三角/弹幕远近克制/擦弹三原则/距离段位: 特征齐备（高度/距离带/TTI/弹幕场/未来占据），移动弹幕宏齐备。
- 薄弱: 盘旋微调（6F 定长步进粒度粗）、欺骗假动作（需一阶读能力——EMA 画像方向正确但统计弱）。
- **攻略自证**（"立回是大量实战后的条件反射"）恰好与 RL 的可学性兼容。

### 2.2 打逆与表里择（16 项）—— **架构性缺失** ❌
- L1: 无任何表里择宏（亚空穴打逆/6D8 2D/假动作左右 JA/44 J2A 压起身全缺）。**66 与 6D 的转身硬直差异**——表/里之分的技术根基——宏层无成对变体。
- L2: 对手转身/朝向可见（facing+turn_recency），勉强够。
- L4: **对手模型无"防御方向习惯"画像**（受压防御桶只统计防/不防，不统计表/里、站/蹲）——择的价值函数缺输入维。
- 判定: 需补宏套件 + 画像维度，策略层可学（择本质是条件化输出，softmax 天然支持）。

### 2.3 压制体系（39 项）—— **固定链可，灵魂不可** ◐❌
- 可: 取消链压制（压制A/B 含 cconfirm 门）、无缝/逃点知识可硬编码进掩码、推板连、堵人（位置特征支持）。
- 不可: ①**放帧/stagger**（"压制中的灵魂"，#54/61/89）——宏是固定帧，无延迟变体; ②**压制树**（2B 后按对手 DD/跳/抢 A 六分支）——确认门只有命中/被防二值，无行为分支门; ③最低空 J6A（库中 j6A 非最低空版）; ④空压转下地 3 择（需空中决策节奏）。
- 判定: 固定压制可达"民工压制"，攻略定义的压制博弈核心（放帧+分支）需要**宏中重决策**能力。

### 2.4 择总表（9 项）—— **执行层半瘫** ❌◐
| 择 | L1 执行 | 判定 |
|---|---|---|
| 中下择（A3 vs 2A） | 2A/6A 有、**3A 无** | 补宏即可 ◐ |
| 蓄力择（H6A/H3A） | **无蓄力语义**（keys_to_input 无按住-释放） | ❌ 执行语言缺失 |
| 打投择 | **无投技宏**（三库全文无投） | ❌ |
| 弹幕体术择（J2B vs J6A） | 两宏都在 | ✅（需策略学会交替） |
| 拍子择（放帧） | 同 2.3 | ❌ |
| 空防不能择（DA/6A/4A） | DA/6A 有、4A 无 | ◐ 补宏 |

### 2.5 连段（12 项）—— **最强项** ✅
Trialmode 宏+confirm 门+等级取消+LIMIT/comboDamage 特征齐备。缺: 目押自适应（固定帧无法目押）、HJC 套件（射击后跳取消宏）。攻略立场（"民工连够用，保证出圈"）恰好是当前覆盖区。

### 2.6 防御与逃压（22 项）—— **"打乱动"的主场，最大缺口** ❌❌
- **正防/错防选择**: 立防/蹲防宏在，但**特征看不到招式段位**——`action//128` 把 2A（下段）与 5A（中段）折进同桶，pose/poseFrame 未用（蓄力状态也不可见）→ 防段位=纯猜。攻略明确"中段技通常更强迫使站防"的博弈在此架构中不存在。
- **DD（回避结界）**: 结界 2/4 宏在，但 **15F 输入窗**要求"被打防的帧立即决策"——当前守方在防御宏执行中无决策权; 6DD/空中 DD/1DD 变体全缺; "DD 点选择学"（攻略按角色按招式给出的安全分级）无数据通道。
- **铜钱/灵击/灵反/刹那**: 全部无宏、无使用时机决策（卡·当前理论可发系统卡但无策略）。
- **插动/乱动（abare）**: 攻略给出明确反应窗（"看到 DASH 启动就 2A"、缝里插 2A/DC 发生 6-13F、2DD 后 36F 不可动）——全部超出决策节奏。R34 清队后一轮决策+宏起手预置 ≥20F 迟到。
- **凹与骗凹**: 升龙宏在; 起身/压制缝时机不可达; "凹是吓人"的心理层 → 对手建模。
- 判定: 反应类 35 项技法中，**当前架构一项都无法在正确帧窗内执行**。这是 L3 时序墙，不是宏库数量问题。

### 2.7 受身起身（8 项）—— 防侧可、攻侧缺 ◐
受身/起身穿/起身无敌知识可硬编码; untech 特征支持受身狩时机。压起身套件（门板/地雷预设、46 择、远 A 押起身帧精度）宏层全缺。

### 2.8 资源（10 项）—— **环境半瘫** ❌
卡组构筑/技能改卡/SC 经济/天气控制: 训练分布内 deck 恒系统卡 → 技能与 SC 卡永不出现（详见 goal_feasibility 文档天花板 2）。灵力控灵可学（特征+势函数在）。攻略的"改卡压制"（妖怪/抄地/地雷/祈雨改出压制形态）整条策略维度不存在。

### 2.9 读/对局论（5 项）—— 一阶可、高阶不可 ◐
EMA 画像+aux 预测=一阶条件化（"他被防后爱反击"）。梅原上级论（挖陷阱/心理/高阶读）需跨局记忆与博弈推理——前馈架构无记忆。攻击性结论: 择的"时效性/移居新岛"动态（#149）本质是非平稳博弈，需要 league+对手池多样性配合。

## 3. 总判定与缺口清单

**覆盖率估计**（按攻略 167 项的可达成性）:

| 状态 | 项数估计 | 说明 |
|---|---|---|
| ✅ 现架构可达成 | ~70（立回大部+连段大部+固定压制+部分资源） | 需训练量与时序无关 |
| ◐ 补件后可达成（宏/特征小改） | ~35（择的执行件、压起身、HJC、画像维度） | 工程量: 宏库+特征扩维 |
| ❌ 架构性缺口 | ~60（反应类 35 项全数+放帧族+表里择+高阶读+卡组维度） | 需三类结构性升级 |

**三类结构性升级**（缺一不可）:

1. **帧级决策通道（L3 时序墙）**——对"择/打乱动/逃压"是充要条件:
   - 事件驱动中断: 打防事件（guardstun 进入）、DD 可用窗、对手 DD/跳/抢 A 启动帧、起身/受身时机 → 触发即时决策（推理延迟需 <3F: 缓存 trunk 特征+仅侧路径前向，或预先算好候选）;
   - 帧窗反应宏: "在 X 事件后第 N 帧出 Y"的参数化宏（攻略已给出全部 N 值——DD 15F、小跳 6F、插动 6-13F 窗，可整表硬编码为反应规则库，RL 只学"何时不反应"）。
2. **感知补维（L2）**: pose/poseFrame 入特征（段位/蓄力可见）; 对手防御方向画像（表里/站蹲/错防率）入对手模型; 招式 ID 级（非 //128 桶）one-hot 或嵌入。
3. **执行库补件（L1）**: 投技、蓄力语义（按住-释放）、DD 全变体、铜钱/灵击/灵反/刹那、放帧变体宏（同招±N 帧）、表里择成对宏、压起身套件、最低空技、HJC。

**一个重要的正面观察**: 攻略自己反复强调立回/反应是"条件反射"（#21/148/151）——即大量高手操作是**"感知→固定反应"对**，这天然适合"事件→帧级规则"的混合架构，不必端到端 RL 学出全部时序。RL 的正确角色是: 学条件化的**选择**（何时压/何时退/出哪个择），帧级规则库负责**执行时机**。这与 goal_feasibility 文档的"宏下帧级残差层"建议收敛于同一方案。

## 4. 与既有结论的合流

- 本文的"时序墙"= 可行性文档天花板 4（动作粒度）的具体化，且证据更强（攻略自带 35 项反应技的帧窗数据）;
- "感知缺维"补足了天花板 1-6 未覆盖的一层（特征盲区: 段位/蓄力/防御画像）;
- "资源半瘫"= 天花板 2（卡组系统）的攻略侧印证;
- 执行优先级建议不变: 若以"能完成所有高手操作"为目标，排序为 **帧级通道 > 感知补维 > 执行补件 > 卡组系统**（前两者解锁"打乱动/择"整族，后两者解锁覆盖率）。
