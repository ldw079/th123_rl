## 2. 可执行方案（分档）

### 2.1 P0（立即，1–2 天；两个窗口）

**P0-1 = task-23（优化瓶颈最小可证伪实验，一次重启窗 ~10min）**
1. `TH123_BATCH_MIN_GAMES`（0/4）、`TH123_BATCH_DECISIONS`（0/12000）：learner 收集器等满再更新；上限保护（陈旧度≤K、内存）；
2. 批放大后 KL 目标带复位（目标 0.01–0.05），自适应 LR 带重建；
3. **值头去动作条件化（方案 A）**：`W1v` 输入去掉 2N 上一动作 one-hot；迁移脚本（删行）+ 旧前缀等价断言 + 新维接线测试；
4. 日志：每批局数/决策数/耗时/lr/KL/值损；env 默认=现行为逐位等价。
5. **验收（24h）**：批≥4 局达成率、`|KL|` 落 0.01–0.05、自适应 LR >0.3、值损方差下降；行为三表（空挥/punish/opp_recovery）移动 → 若移动则"优化是瓶颈"成立，暂缓结构改造；若不动 → 进 P1 结构改造决策。

**P0-2 = task-24（死重清理，纯代码/测试，不重训）**
- C1 §15 k4 槽位改新语义（有效秩 24/24）；C2 308–315 注释+门禁断言；C3 删除 Wf 头+迁移旧档（或注释 dead + 不再存盘）。
- 验收：秩 24/24、参数 −108k、旧前缀等价、门禁/变异红、行为不变（24h 行为三表与 P0-1 前无显著差）。

**P0-3 = F1 决策（Lead 出选项，用户裁定）**
- 方案 A：重建同代码对照臂（+1 actor/learner/game，CPU 成本 ~+1 核；两臂同代码不同配置）；
- 方案 B：重定义预注册终点为"时间窗 A/B（同代码、开关差异）"，放弃跨代 LE 斜率。

### 2.2 P1（结构改造，需先过 P0 门 + 用户批；设计先行）

**P1-a 记忆 v1（先帧栈后序列）**
- 步骤：①视觉 3→6/9 帧通道（conv 首层输入改，重训；1–2d）②最近 8 决策动作嵌入（小 attention/MLP，加性偏置→可学习交互；2–3d）；
- 验收：帧陷阱合成场景命中率、防御 20F 响应 ≥30%、空挥 ≤60%（M3 子项）；
- 风险：帧栈信息冗余有限（48→144ms）；真记忆需 recurrent+序列数据，排后。

**P1-b 动作残差层 v0**
- 设计：每决策宏 logits（N）+ 残差头（9 方向 × A/B 二值 × 1–2 帧）；执行器叠加，宏分支/branch 保持；env 开关，3 角色逐步开；
- 验收：走位/放帧类行为指标（墙角脱离率、空挥、被防后惩罚）、人测；
- 风险：宏语义冲突（残差打断 confirm/branch）、执行器改动大、重训；**先 1 角色 A/B，成功再推 3 角色**。

**P1-c 其它**：B2 BC 重建（低载窗）、A4 epochs/γ 实验、C3-b Wf 辅助损失。

## 4. 可行性判定汇总（冷静结论）

- **A1/A2/A3/C1/C2/C3 = 高可行**（纯代码/迁移/测试，1–2 天可闭环；A3 需模型迁移工具）；
- **P1-a/P1-b = 有条件可行**（改执行器/数据格式 + 重训，5–8 人日；需 A/B 与回滚；先单角色验证）；
- **D3/E1 = 条件性**（搜索收益不确定；算力受 CPU 红线/预算约束）；
- **"当前形态达超人" = 不可行**（评估结论，与 10-04 一致）——P0/P1 完成后可达"人类中上/稳定胜 Lunatic COM"；超人需要 P1-b+P2 算力/架构组合，且需先重建可比对照臂与绝对强度标尺；
- **数据量已足够**（~20–24 天等效对局/角色），继续堆训练时间不是有效杠杆。

## 6. 风险清单（执行时必看）

1. 值头迁移错误 → 旧前缀等价断言（1e-6）+ 迁移备份；
2. 批放大导致陈旧度/内存上升 → 上限保护（陈旧≤K、批≤N 局）+ 监控；
3. 帧栈/残差层重训不稳定 → 单角色小步 A/B + env 回滚 + 旧档保留；
4. 归因混（多项同窗）→ env 开关分项 ablation；
5. 对照臂/LE 口径错 → 先定 D2 再跑任何"学习效率"结论；
6. CPU 红线：actor 增加/重负载 → 必须经 load_gate + R14 族线监控。
