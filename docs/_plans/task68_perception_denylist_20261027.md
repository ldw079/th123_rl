# task-68 全状态感知 v1 + 红线段 denylist 设计（2026-10-27，离线）

> 用户裁定：除红线外全状态可读；红线=①对手输入指令 ②晴岚天气对手卡片信息（手牌/卡槽/卡身份/次数）
> ③极光天气实际天气 ID/timer 原始字段；**允许可观察推断**（推断逻辑须文档+auditor 核，不得用被禁字段）。
> 不部署；与 W4 一次迁移（CORE 扩维）合并，禁止二次迁移。

## 1. 只读字段盘点（候选）
- 己方：位置/速度/HP/灵力/卡槽/当前卡/动画/action/hitstop/untech/comboDamage/天气可观察效果；
- 对手：位置/速度/HP/灵力/**动作动画/段位/hitbox/硬直**（非输入）；卡牌仅可观察已使用/冷却（不读手牌/卡槽/身份）；
- 弹幕：全部弹丸位置/速度/类型/存活（非输入）；
- 天气：可观察效果/环境表现；**晴岚对手卡信息 masked**；**极光实际天气 ID/timer 原始字段 masked**。
- 红线段实现：特征构建前按 denylist 过滤；任何绕过路径（调试/探针/日志）同样禁；审计测试。

## 2. denylist 规格
| 红线 | 禁用字段/路径 | 测试 |
|---|---|---|
| 对手输入 | 对手 keys/方向/输入缓冲，任何直接读取 API | 真实帧/日志断言无读取；静态 grep 禁用符号 |
| 晴岚卡信息 | 对手手牌/卡槽/卡身份/次数（ID+名称） | masked 特征位=0/常量；单元测试 |
| 极光天气 | 实际天气 ID/timer 原始值 | masked；仅允许从可观察效果推断（文档+审计） |
- 推断白名单：极光→从画面/环境效果推断，不得用 raw ID/timer；记录推断模型输入源。
