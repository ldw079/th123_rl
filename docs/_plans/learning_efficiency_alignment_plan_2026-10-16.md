## ② 可执行方案（LE-0..LE-8，四波+对照臂）

### LE-0 主测量设计与仪表（1 天，BH 窗内并行——仪表侧例外）

**（a）孪生对照臂（本方案的核心保险，v2 新增）**：
- BH 开始时冻结一个 **pre-BH 快照**（当前带病栈），治疗窗期间以
  ~1/4 fleet 算力**同预算并行训练**作为对照臂——不享受 BH 修复与
  LE 任何改进；
- 主测量周期（LE 波 1 落地后 ≥2 周、每边 ≥1500 局）结束后对照臂
  退役，算力归还；
- 它测的正是用户要的命题：**"没有这一系列改造会怎样"的反事实**；
- 算力代价入 BH-5 裁定项（对照臂期间主臂吞吐 ~3/4——学习效率
  验证本身值这个价，一个周期后止损）。

**（b）三分母口径**：主终点=**每千局**学习进度（样本效率，对齐
"2000 局"之问）；次终点=每天（含占空比与吞吐）；诊断口径=每次
更新（learner 效率，LE-6 用）。

**（c）三段尺斜率**：COM 阶梯（启蒙段）→ league 固定池胜率斜率
（中段，防 COM 饱和）→ B 标尺节律对局（终段泛化）。

**（d）"相对 2"操作化**（v1 三段刻度维持）+ **每千局斜率仪表**
（BH-1 八表之上加斜率口径）。

### LE-1 情境重演引擎（a 离线 1.5d【BH 窗内可并行】+ b 激活 1d【后 BH】）

- **LE-1a 情境库构建（纯离线，不触训练，BH 窗内并行——v2 拆分）**：
  三数据源（oracle 分片/自打日志/distill_rows）提取情境快照+
  {连段机会/天气×情境/对手风格/对位}标签 + TTL 保鲜 + 弱点热度
  评分逻辑（读 BH-1 仪表）；
- **LE-1b 注入激活（后 BH）**：优先走 distill/bc_extra 通道；
  **注入混合比上限（初始 ≤20% 批占比）+专项 A/B**（v2 新增——防
  回放分布偏离策略分布过远）；tm_env 快照开局为二期（含 C9 评估）；
  fleet 兼容：actor 侧构造+高价值优先入批（learner 17.7s/批容量
  保护）；
- 试点：连段学校最小闭环（指定连段 N 次重演内成功率 X→Y）。

### LE-2 人类先验通道补全（1.5 天；表提取段可 BH 窗内并行，特征段随迁移波）

### LE-3 即时反馈加速（0.5 天）

S-1/CE-1 惩罚通道事件驱动加速（明确被反制=大步更新）。

### LE-7 联盟多样性与泛化守卫（1 天维持）

多样性指数 / 静态种子过拟合差值（同角色扰动种子对照）/ B 标尺

## ③ 验收途径（v2：预注册终点）

### 主终点（预注册，到点宣判——杜绝事后解释）

**波 1 落地后 ≥2 周、主臂 vs 对照臂各 ≥1500 局**：
- **P1（主）**：每千局学习进度（三段尺斜率综合）**主臂 ≥2× 对照臂**；
- **P2（次）**：league 固定池胜率斜率，主臂较对照臂提升 ≥50%；
- **P3（能力专项）**：连段学校——新连段掌握所需重演次数 ≤20
  （对齐人类"练 10-20 次"）；惩罚→行为改变延迟较基线 EMA 缩短
  ≥50%；天气切换后表现恢复帧数可测且收敛。
- **判定纪律**：P1 达成=系列成功宣判；P1 未达但 P2/P3 达=部分
  成功，LE-8 复盘定位瓶颈（超参/注入比/对照臂算力不足等）；全未
  达=系列假设有误，复盘后重定向（不静默续投）。

### 逐组件验收（v1 表维持，增补）

| 组件 | 增补判据（v2） |
|---|---|
| LE-0 | 对照臂启动时间戳≤BH 开始+1 天；三段尺斜率仪表产出首份周报 |
| LE-1 | 注入混合比 A/B 结论留档（20% 上限的取舍得证）；连段学校试点闭环 |
| LE-3 | 在线/离线一致性测试：同一 shard 双路径 punish 率逐位一致 |
| LE-8 | 判定报告四件：斜率对比/终点宣判/未达项归因/续投建议 |

### 红线自检（v2 增补）

对照臂期间主臂吞吐不低于 3/4（超出即暂停对照，测量让位训练）；
预注册终点不可事后修改（修改=新系列重新立项）；LE-3 同代码路径
约束；其余 v1 红线全部维持（奖励零改动/双门控/mod 零改动/TTL）。
