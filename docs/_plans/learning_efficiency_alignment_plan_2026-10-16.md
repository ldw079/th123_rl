# 学习效率与人类能力对齐方案（LE-0..LE-7）— 2026-10-16

> 性质: **学习质量纲领**（后 BH 执行）——"人类 2000 局 vs 模型数千局仍弱"
> 的样本效率差距 × 四项人类能力（预判/快速连段/针对性立回/天气适应）
> × 即时反馈与主动性先验，收敛为单一执行计划。
> 触发链: 用户 2026-10-15/16 三轮讨论（2000 局之问→四能力富化→即时
> 反馈与主动先验）。
> 格式: 遵循 PLANNING_AGENT.md 三段式（现状核验/可执行方案/验收途径）。
> 编号前缀 **LE-**（learning efficiency）。
> 前置依赖: **BH 方案先行**（感知为真+锚健康+仪表在位）——本方案除
> LE-0 外全部排在 BH 退出之后；BH 未退出前本方案只排队不施工。

## ① 现状核验

### 1.1 问题的校准形态（数字锚定）

- reimu 累计 **485 万次决策**，按每局数百决策折算 ≈ **数千局等效**
  （跨全部栈世代累计）——**模型打过的局数不比"2000 局人类"少，水平
  差着一个档**。吞吐非瓶颈（480tps≈8 倍速，2000 局=日级）；
- **真瓶颈 = 每局样本的 learning per game 比人类低约一个数量级**。
  "AI 能否 2000 局达标"的答案是：局数口径轻而易举，样本口径是本方案
  的战场。

### 1.2 人类能力 × 模型等价物 × 健康度（讨论定稿）

### 1.3 核心收敛（讨论的结构性结论）

四能力+即时反馈**收敛于三套基建+一个实验**：
- **A 先验/语义通道**（表+特征）："知道该预期什么"；
- **B 情境重演引擎**（唯一真正的新建）：连段学校/天气拉平/风格分层/
  对位练习共用同一引擎的不同调度器——数据源三件全就位（distill_rows
  /oracle 分片/自打日志）；
- **C 记忆/适应回路**（GRU+punish+校准）：S 系刚上线待观测；
- **M 局内适配头**：唯一逼近"人类局内改权重"的实验，受控开展。

### 1.4 用户未提及、本方案自行补入的方面（六项）

1. **"相对 2"不可测**——目标无操作化定义，学习效率永远无法判定
   达成 → LE-0；
2. **超参陈旧**——动作空间 ~40→88-95、特征 260→358，但 lr/entropy/
   clip/GAE 全是旧栈时代标定；88+ 宏下熵系数直接决定探索与被动
   （熵坍缩可能是被动病的共犯）→ LE-6；
3. **学习器吞吐是隐形瓶颈**——scenario 重演提高数据密度，但 learner
   17.7s/批的更新容量有限，密度必须配 actor 侧过滤（高价值情境优先
   入批）→ LE-1 设计约束；
4. **联盟过拟合/自博弈塌缩**——静态种子对手可被非可迁移方式剥削；
   均匀自博弈会窄化策略分布；league 多样性与"对人类泛化"需要守卫
   → LE-7；
5. **锚退火与灾难性遗忘**——BC_W_MIN=0 后无护栏，强世代策略可能
   漂移失稳 → LE-6 周期性回锚实验；
6. **情境库陈旧**——重演陈旧快照会教过时情境 → LE-1 带 TTL 保鲜。

## ② 可执行方案（LE-0..LE-7，四波）

### LE-0 目标标定+学习效率仪表（0.5 天，可与 BH-1 同批——仪表侧例外）

1. **"相对 2"操作化**：三段刻度——①COM Lunatic 稳定胜率 ≥90%；
   ②league 全池（含剥削者）胜率 ≥55%；③对人 BO5 场均拿局 ≥1
   （B 标尺现有基建）。目标的达成判定=三段刻度+曲线斜率（每千局
   COM 阶梯升档数），不再靠体感；
2. **学习曲线仪表**：BH-1 八表之上加"每千局学习进度"口径（COM 阶梯
   斜率/续打率斜率/对位连段斜率）——"2000 局速度"从此可判定。

### LE-1 情境重演引擎（2.5 天，**本方案的核心新建**，BH 退出后首件）

1. **情境库**：三数据源（oracle 分片=完整状态流 / 自打日志=CE-0 格式
   / distill_rows=轻量情境索引）提取情境快照——(状态帧, 上下文标签)，
   标签维度：{连段机会(命中确认+浮空+位置) / 天气×情境 / 对手风格 /
   对位}；TTL 保鲜（陈旧快照出库）；
2. **分层调度器**：同一引擎四种调度（连段学校/天气拉平/风格分层/
   对位练习），按 BH-1 仪表的弱点热度加权选择重演情境；
3. **注入通道**：优先走已有 distill/bc_extra 通道加权回灌（零新机制）；
   tm_env 快照开局作为二期（需验证 mod 侧状态恢复能力，含 C9 评估）；
4. **fleet 兼容+吞吐约束**：重演在 actor 侧构造（不等 learner）；
   高价值情境优先入批（防 learner 17.7s/批容量被稀释数据挤占）；
5. **试点验收**：单条连段在情境库内成功率 X→Y（N 次重演内）——
   "连段学校"的最小闭环。

### LE-2 人类先验通道补全（1.5 天，与 CE/JZ 迁移波合批）

1. **预测校准特征**（+2 维）：本局 aux 预测命中率滚动值（我对这个
   对手读得准不准）——读准则策略可信预判，不准则退回反应式；
2. **对策先验表**：fangyu.txt 逐角色对策章节 → "对位→对策要点"表
   （JZ-2 同管线，出处标注）；形态=特征或掩码降权，与 BH-4.3 体型
   限定表同批；
3. **天气预报特征**（+2 维，JZ-3.5 转正）：下一预报天气 ID+读数进度
   ——人类提前 10 秒为下一天气布局的等价输入；
4. 开局倾向先验（league 静态对手的固定种子开局习惯查表，可选）。

### LE-3 即时反馈加速（0.5 天）

S-1/CE-1 惩罚通道加**事件驱动加速**：明确被反制（我出招→被命中→
我未命中）时大步更新，替代均匀 EMA——对人类 one-shot 学习的最直接
近似；配套仪表：**惩罚→行为改变延迟**（被反制后该类招复用率下降
50% 所需帧数），与人类"立刻停用"对标。

### LE-4 主动性先验实验（0.5 天+A/B 窗）

初始策略对攻击/前向宏加 logit 偏置（出生即主动，RL 学何时收手）
——与"奖励修正被动"相比因果结构更对（人类先 prevent 后 learn）；
小规模 A/B，判据=BH-1 积极性仪表+league 胜率不降。主通道仍是 BH-4
修好的 BC 锚（专家=主动性先验本体），本实验是补充验证。

### LE-5 局内适配头（2 天，实验项，双门控）

门控①：BH 退出+LE-1 仪表能分辨收益；门控②：先纯观测（adapter
梯度更新但只记录不生效，看"若生效会改什么"的分歧率）。
设计：side-path 末端独立 adapter 层，每回合末用本回合轨迹 2-3 步
小学习率更新，局末重置；**只动 adapter 不动主干**；fleet 活在 actor
侧；步长/重置为红线参数；A/B 判据=局内适应速度（对位连段/续打率
的局内改善斜率）。漂移监控：adapter 更新前后策略熵变化。

### LE-6 样本效率算法审计（1.5 天，A/B 合集）

1. **ACCUM_EP 1→3 回摆**（当年为速度降档，fleet 有余量后重 A/B）；
2. **熵系数审计**：88-95 宏下的策略熵曲线+熵系数扫描（熵坍缩与
   被动病的共犯检验）；
3. **lr/clip/GAE 重标定**：栈稳定后的小网格（冻结窗后一次性）；
4. **BC 周期性回锚实验**：BC_W 按"策略漂移度"自适应或周期小幅回灌
   ——对冲灾难性遗忘（当年改 0 的"平均风格拉力"顾虑用小步幅+漂移
   门控规避）。

### LE-7 联盟多样性与泛化守卫（1 天）

1. league 多样性指数（策略分布熵/克制环闭合度）周期报表；
2. 静态对手过拟合监控：对静态种子胜率 vs 对扰动种子（同角色不同
   种子）胜率的差值=过拟合度；
3. B 标尺（人机 BO5）节律化：每两周一次固定测量员对局——泛化的
   最终检验不依赖 league。

## ③ 验收途径

### 逐组件验收

| 组件 | 验收 | 判据 |
|---|---|---|
| LE-0 | 目标可测 | 三段刻度+每千局斜率口径上线；"2000 局速度"=COM 阶梯斜率与人类对标曲线的比值可计算 |
| LE-1 | 试点闭环 | 连段学校：指定连段 N 次重演内成功率显著提升；天气拉平：分天气表现方差收窄；调度器按弱点热度响应（仪表联动验证） |
| LE-2 | 先验入位 | 校准特征行为测试（读准/读不准两态可分）；对策表逐条出处；预报特征与真实天气演化对齐率 |
| LE-3 | 延迟对标 | 惩罚→行为改变延迟（帧）相对基线 EMA 显著缩短；不误伤（未惩罚类的复用率不变） |
| LE-4 | A/B 判定 | 积极性指标改善且 league 胜率不降 |
| LE-5 | 双门控+分歧率 | 纯观测期分歧率数据先行；生效 A/B 局内适应斜率改善且熵稳定 |
| LE-6 | A/B 合集 | 每项独立小样本 A/B 结论留档；至少一项样本效率显著提升 |
| LE-7 | 守卫上线 | 多样性指数/过拟合差值周期报表；B 标尺节律对局入档 |

### 总体验收（对齐"人类 2000 局"的判定）

**主判据 = 学习曲线斜率**：在 BH+LE-1 落地后的首个千局区间内，
COM 阶梯升档速度、续打率/对位连段/积极性仪表的每千局改善量，与
"人类 2000 局从入门到相对 2"的等效斜率对比，给出**可达/不可达/
差多少**的定量结论。三项能力专项判据：连段=新连段掌握所需重演
次数（对齐人类"练 10-20 次"）；预判=校准特征驱动下的读准-读不准
行为分化；天气=天气切换后表现恢复帧数（对齐人类 1-2 轮适应）。

### 红线自检

奖励零改动（LE-4 是初始化偏置非奖励；若升级为奖励项走裁定包）；
本方案除 LE-0 外全部后 BH（冻结纪律）；LE-5 双门控+只动 adapter+
局末重置（稳定性红线）；mod 零改动（快照开局若需 mod=二期 C9
评估后另议）；所有 A/B 独立留档；情境库 TTL 防陈旧教化。
