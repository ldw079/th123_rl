## 2. 试点（建议顺序，均需 Lead/用户批窗）
1. **决策延迟基准**（无训练）：测量当前 actor 决策 P50/P99 + H1 Transformer T=16/32 batch1 延迟，对标 5–10ms；
2. **冻结基准报表**：把现有 eval_matrix 冻结为赛季基准（对手池/种子/局面集/hash），周报；
3. **人类输入克隆小试点**（backlog，task-74 地基完成前不做）：用全库索引→候选场景库→输入克隆离线评估；
4. **风格 ghost**：从录像库提取风格特征（task-69）→ 作为对手池/评估参考（不训练）。

## 3. 成本/风险
- 成本：延迟基准 0.5 天；冻结基准 1 天；输入克隆需 task-71 表达力地基（否则 74% 可表达率上限）；
- 风险：外部参数不可直接迁移（不同游戏帧率/输入语义）；人类数据噪声/版本差异（已见 0.58% 解析失败）；
  R1/公平边界不可借外部做法绕过（对手输入/晴岚/极光红线仍禁）；
- 反债（R16）：不建一次性外部管线；冻结基准/风格档案作为长期资产；
- 验收（R19）：人测最高真值；外部借鉴仅作参考，不替代用户验收。

## 4. 结论
- 优先吸收：**决策延迟目标、冻结锦标赛基准、风格档案 ghost、人类输入克隆**；
- 暂不吸收：大规模端到端预训练（Faynt 840k）→ 等 task-71/72/74 地基+用户批；
- 与 task-70/71/77/67/69 的接口已在本表标注；材料供 Lead 审。
