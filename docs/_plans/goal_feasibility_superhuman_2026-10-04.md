# 目标可行性评估：现有模型架构能否达成"超人教学性模型"

> 日期: 2026-10-04 · 依据: 第十四轮审查的全量代码核验 + 重启后 30+ 小时实跑数据
> 性质: 架构级评估（非缺陷审查——缺陷见 full_review_2026-10-03/04 系列报告）
> 结论速览: **地基方向正确、工程质量扎实，但照当前形态到不了"超人教学性模型"——存在六个硬天花板。每个天花板都有可叠加的升级路径，无需推翻重来；其中算力一项差 2~3 个数量级，且"教学性"维度目前完全不存在。**

---

## 0. 目标拆解

"超人教学性模型" = 两个正交要求：

| 维度 | 含义 | 现状 |
|---|---|---|
| **超人** | 稳定超越最强人类玩家（含 Lunatic COM、顶级对战者） | 距离遥远（对 Lunatic COM 8%，经 22h 训练） |
| **教学性** | 能向人类示范/讲解/校准: 局面评估、最优应对、坏习惯惩罚、难度可调 | **维度为零**（无任何教学层构件） |

---

## 1. 地基评估：什么是already对的

架构与 AlphaZero 类"自对弈+完美信息"配方同构的关键部件齐备，且经六轮审查逐行核验：

| 部件 | 状态 | 对超人目标的意义 |
|---|---|---|
| mod 层完美状态感知（105B 锁步包） | ✅ 正确（协议位级三方核验） | 严格优于任何抓屏方案；感知无损 |
| 确定性锁步（同输入→同轨迹） | ✅ 实跑验证 | 可复现、可回放、可分支——搜索与教学的前提 |
| tps480 三实例并行 + 监督自愈 | ✅ 30h 零死亡 | 采样基础设施成立 |
| 宏动作空间 + 双确认门 + 情境掩码 | ✅ | 探索空间从 2^9 帧级坍缩到 N 宏，可行 |
| 势函数塑形（差分不可刷分） | ✅ 数学保证 | 奖励设计的正确骨架 |
| 对手子网络 + 动作预测辅助损失 | ✅ aux 命中 31-46% | 对手条件化的雏形 |
| 治理体系（门禁 283 断言 + 96 变异全拦截） | ✅ | 长期迭代不失控的工程保障 |

**判定: 作为"练到人类中上水平"的系统，现形态合理。**

## 2. 六个硬天花板（按与目标的差距排序）

### 天花板 1：算力/样本效率——差 2~3 个数量级（最硬）

- 实测吞吐: ~50 万决策/天/角色、~550 次更新/天/角色、有效逻辑帧 85fps/实例（tps480 理论 436 的 ~20%）。
- 瓶颈结构: numpy 手写 PPO 跑 CPU；每局串行一次更新（局首 join）；三实例即并行上限。
- 参照系: 公开自对弈超人项目无低于亿级对局量者；强人类玩家个人经验亦在千万帧级。
- **升级路径**: ① GPU 化（PyTorch 迁移；im2col 手写卷积的算子映射直接，`ppo.py` 前向/反向已按层组织）; ② 多环境批式单 learner（消除"每局 join"串行，向 IMPALA 式推进器靠拢）。预期吞吐 ×50-200。
- **不升级此条的后果: 其余一切升级都无意义。**

### 天花板 2：训练对局缺整条卡牌系统（本轮核验的新发现）

- `tm_env.py:192`: `deck = list(range(1, 21))`——**训练局永远使用 1-20 号系统卡组**。
- 三重后果:
  1. 技能卡（100+）永不入手机 → R17 技能等级特征（段 11 的 230-237 维）恒 0、`adjust_script` 等级取消机制永不触发——**整套已建成的技能子系统在训练中是死的**;
  2. 符卡（200+）永不入手机 → 卡·鬼神玉/妙珠等大部分 SC 宏的可用门**从未打开过**（`_sc_usable_mask` 要求目标卡在手）;
  3. 卡组构建（Soku 策略深度的一半：deck 选择、天气协同、技能升级路线）完全不在训练分布内。
- **升级路径**: deck 采样器（随机/课程化卡组入训练局）→ 技能特征与 SC 宏自然激活 → 最终把 deck 选择本身交给策略（超人的必要维度）。这也是让既有 R17/R39 投资真正产出的前置。

### 天花板 3：永久模仿锚与超人方向冲突

- `ppo.py:122-123`: `BC_W_MIN = 0.05`——BC 锚退火到 5% 后**永不归零**。
- 锚的构成: oracle 专家 BC（真人类数据，尚可）+ `_expert_rec` 手写弱启发式（距离→立防/jB/5A/连段A，train_tm.py:1246-1272）。
- 本质: 存在一条永久指向"平均人类风格"的梯度拉力。超人的必要条件是能彻底离开人类先验。
- **升级路径**: 删除 `expert_rec` 一路; bcw 下限改 0（或设定"评估超越教师即关锚"的自动条件）。温度地板 0.5 同步放开。

### 天花板 4：动作空间上限 = 人类技法词汇表

- 策略在"选哪个人类写好的宏"上做超人决策，不能发明宏外帧级新技; 反应速度被宏时长封顶（决策节奏=宏粒度，R34 中断仅是防御侧补丁）。
- 附带质量风险: R44 生成的 17 个新宏库仍带未规范化的"吞键死招"脚本（第十四轮 HIGH-2）——扩容本身是这个天花板的组成部分。
- **升级路径**: 宏层之下叠**帧级残差修正头**（宏执行中允许有限微操: 提前取消/延长/方向修正）——探索空间可控打开，超人级反应成为可能。宏层保留为"战略动作"，残差层承接"战术微操"。

### 天花板 5：无记忆、无联赛

- 前馈策略 + 75 维 EMA 对手画像桶; 无循环网络、无跨局适应、无 league/exploiter 结构; 段 11 对手 one-hot 仅 3 宽（装不下 20 角色，第十四轮 MEDIUM-4）。
- 人类高手核心能力之一是局内读惯与局间调整; AlphaStar 式超人的标配是主选手+剥削者+历史池。
- **升级路径**: ① 20 角色扩容（已备，待修 4 项缺陷）正是 league 前提; ② league 调度器（对手池按胜率加权/剥削者注入——R43 动态池已具备一半能力）; ③ 段 11 升级为角色嵌入或哈希桶; ④ 远期: 循环策略网络（跨局记忆）。

### 天花板 6：奖励与"赢"未完全对齐（已有实证）

- 实测: suika 在 COM 局**输了却平均赚 +11.7 回报**（KO 通道 -14 被擦弹/规避/势差收入盖过，2026-10-03 21 时段）。
- 塑形经济学已调过一轮（两级擦弹费率），但结果信号边际拉动力仍不足。
- **升级路径**: 提高回合胜/KO 权重或进一步压微奖励; 把"回报-胜率相关性"做成常规仪表（[matchup] 数据已足够自动计算）——相关性跌破阈值即报警。

## 3. "教学性"维度：目前为零，但地基意外地好

**现缺**: 无局面讲解、无反事实演示、无难度校准、无不确定度标注。

**三个被低估的现成杠杆**:

| 资产 | 教学用途 |
|---|---|
| 确定性锁步 + `SET_HEALTH/SET_POSITION/SET_WEATHER` opcode | **任意局面重置并分支重跑**——"同一局面五种应对"、"坏习惯的最优惩罚演示"的核心能力; mod 早已支持，现仅 hitlab 用过。全项目最被低估的资产 |
| standard_tree 审计管线 | 手写教义树 vs 模型行为的偏离矩阵 = 教学树的种子（"此时标准应对是X，模型选了Y，差在哪"） |
| oracle 专家数据（191 局/226 万帧，ilog 精确对齐就绪） | 人类示范对照——教学素材与"模型为何更强"的差分来源 |

**需新建**: 局面评估讲解（价值网+分支差分自动生成）、条件化惩罚演示（对手建模驱动）、校准难度对局（限制性手法: 固定开局/禁卡/降反应档）、模型不确定度标注（教学必须知道自己何时不确定）。

## 4. 结论与路线图

| 判断 | 结论 |
|---|---|
| 现形态可达上限 | 稳定胜 Lunatic COM、人类中上水平（修掉卡牌缺失后，数周-数月量级） |
| 现形态不可达 | 超人竞技水平 + 教学功能 |
| 是否需要推翻重来 | **否**——六个天花板全部是可叠加升级，非原则性设计错误 |
| 最大风险 | 算力差距（不解决则其余皆空谈）; 格斗游戏自对弈超人**无公开先例**（研究级目标） |

**升级优先级**（以超人为目标）:

1. **GPU 化 + 批式多环境 learner**——一切的前提，吞吐 ×50-200;
2. **训练局接入完整卡组系统**（deck 采样/技能卡入池）——激活已建成的技能子系统，补上策略深度的半壁;
3. **删 expert_rec、BC 锚允许归零**——解除对人类先验的永久锁死;
4. **league 调度**（20 角色池 + 剥削者 + 胜率加权对手）——R43 动态池已备其半;
5. **宏下帧级残差动作层**——打开超人级反应与微操空间;
6. **教学层**（复用状态重置 opcode 为核心杠杆）——评估讲解/惩罚演示/难度校准/不确定度。

**执行顺序建议**: 1→2 可并行（互不依赖）; 3 是一行改动随时可做; 4 依赖 R44 四项缺陷修复; 5 是研究性最强的一步，建议在 league 稳定后启动; 6 可在任何时点以轻量形态起步（教义树讲解不依赖超人流强度）。
