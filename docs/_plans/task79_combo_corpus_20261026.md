# task-79 连段完备语料/爆灵推板宏 设计 v0（2026-10-26）

> 用户要求：所有采集连段（含 trailmod 源）能打完 + 压制/推板/爆灵有效。
> 结论：**当前样本不够**（lab 50 用例/BC 锚 509 行/人类 replay 61,866 局未按连段段入库/trailmod 未纳管）；
> 本任务=全来源盘点+场景矩阵+爆灵/推板宏族设计；实现阶段在 phase-3b 后。

## 2. 场景矩阵（目标 2,700+ 用例）
- 3 角色 × ~15 起手 × 5 对手状态（站/蹲/空/受身/Guard）× 4 位置（近/中/远/板边）× ≥3 reps ≈ **2,700**；
- 每用例固定：角色/对手角色/开局距离/天气/卡组/种子（可复现）；replay 严格（≥3 场景）；
- 样本门：每宏≥3 场景；lab 100% 目标=固定场景下严格 replay（失败→executor 修复或标"不可实现"+证据）。

## 3. 爆灵/推板宏族（当前宏库无专门族）
- **破防/爆灵**：破防（Guard crush）连段、爆灵（Spell/系统）消耗与收益、爆灵后追击；
- **推板/corner carry**：推板连段、板边压制循环、角落择；
- **压制循环**：安全压、跳压、空挥惩罚、立回转压制；
- 验证：帧表/REACH/hitlab + trailmod 复核；BC 锚补标签（连段宏标签）。
- 验收：lab 场景矩阵 100% 完成率（固定场景）；实战指标分离（选择率/命中结算/打断率 24h）。

## 4. 阶段/依赖
- 设计+盘点（1–2 天，离线，不占窗）→ phase-3b 实现 → 爆灵/推板宏 → BC 标签 → 窗；
- 与 task-71/72（表达力/决策频率）、task-74（数据，backlog）联动；R15/R19（用户看 replay 验收）。
- 风险：样本不足/连段段切分噪声/trailmod 格式未知；反债：corpus schema 一次设计，不建一次性管线。
