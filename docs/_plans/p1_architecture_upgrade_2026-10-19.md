**为什么先 Gen-1**：评估建议的"批放大"是最便宜的可证伪杠杆；值头 bug 与死重清理是纯机械修复；**决策历史记忆**用紧凑元数据实现"跨决策记忆"，避免视觉帧栈的 2× 存储/IO 代价（feats=14400/dict 已是 47.7MB/局）。四者共用一次模型迁移+重训，成本最低。

## 1. Gen-1 详细设计

### 1.1 决策历史记忆 v1（`TH123_MEM_DECISIONS`，默认 0=现行为；实验档 8）
- **存什么**（每决策，紧凑 int16/uint8，~16–24B/决策）：
  - 我：上 8 拍宏类别（MELEE/SKILL/BULLET/MOVE/GUARD/JUMP/OTHER，7 类）+ 是否命中/被防/空挥（3 位）；
  - 敌：上 8 拍对手动作类（8 类）+ 事件标志（startup/recovery/guard-stun/untech，4 位）；
  - 全局：当前是否处于自己/对手惩罚窗、连段计数（0-7）。
- **网络**：序列 → 小 MLP/1 层 GRU（输入 ~20 维/拍 → 32 → 64），输出并入侧通路（`Ws1` 输入 concat 或加性偏置；**不进值头**，值头只吃状态）；新增参数 <20k。
- **Episode schema v3**（向后兼容）：新增 `hist` 数组（决策数 × 8 × 3 int8 左右，≈24B/决策）；learner 缺 `hist` 时补零（旧档兼容）。
- **迁移**：现模型保留全部权重；新增历史分支参数 `N(0,0.01)`；`TH123_MEM_DECISIONS=0` 时历史输入全零 + 分支输出经 0 门控（逐位等价旧 logits），保证可回滚/可 A/B。
- **测试**：env=0 与旧 logits 1e-6 等价；env=8 时仅历史变化会改变 logits；episode 读写往返；旧档缺 hist 兼容。

### 1.2 值头去动作条件化（方案 A）
- 值头输入 `W1v` 去掉 side 向量中"上一拍 2N 宏 one-hot"段（value 只吃状态+sides 其余部分）；
- 迁移：`W1v` 删对应 2N 行；旧前缀等价断言；值损方差对比（迁移前后 100 批窗口）。

### 1.3 批放大 + KL/LR 复位
- `TH123_BATCH_MIN_GAMES`（0/4）、`TH123_BATCH_MIN_DECISIONS`（0/12000）：等满再 update，上限保护（陈旧≤K、批内存）；
- KL 目标带复位（0.01–0.05）；日志 lr/KL/批规模；验收：批≥4 局达成率、|KL| 落带、自适应 LR>0.3。

### 1.4 死重清理（与 Gen-1 同批）
- §15：k4 槽位改新语义（`corner_urgency`），有效秩 24/24（不扩维）；
- 308–315：注释"20→28 角色扩展区"+ 门禁断言；
- Wf1/Wf2（108k）：**删除** + 迁移工具（模型档尺寸变化、读兼容断言）；若用户想保留，改为"接通辅助损失"（Gen-2 再议）。

## 2. Gen-1 执行与验收

**执行（零停机）**：scratch 实现 → 单测 → 门禁 → 变异红 → commit。
**迁移窗（≤10min）**：停 main → 迁移三模型（备份 `*_pre_p1gen1.npz`）→ 重启带 `TH123_MEM_DECISIONS=8`、`TH123_BATCH_MIN_GAMES=4`（其余 env 默认）→ 验收（主臂/对照臂、`[mem]`/`[batch]` 启动行、新 episode schema v3、≥10 拍 wd 无 0.00）。
**24–48h 读数**：①值损方差/|KL|/LR/批规模 ②行为三表（空挥/punish/opp_recovery）+ 板边/逃压/上方迂回 + SC% ③M3 子项（空挥≤40%、防御 20F 响应≥30%、连段≥50%、SC≥3%）④人测 1–2 局（用户）→ **Gen-2 决策门**。
**回滚**：`TH123_MEM_DECISIONS=0` + `TH123_BATCH_MIN_GAMES=0`（行为等价）或恢复备份模型。

## 3. Gen-2 动作残差层 v0（设计要点，Gen-1 读数后开工）

- 每决策：宏 logits（N）+ 残差头（方向 5：无/前/后/上/下；A/B 二值；持续 1–2 帧）；
- 执行器：`macro_executor` 叠加残差（不改宏 branch/confirm 语义；残差仅在宏步间隙生效）；
- 掩码：残差只在未处于不可打断宏时生效；env `TH123_ACT_RESID=0/1`；
- **A/B**：先 reimu 单角色（`TH123_ACT_RESID=1` 只对 reimu actor/learner 开），mtime 窗口 48h 对比同角色旧窗；
- 验收：墙角脱离率↑、空挥↓、punish↑、人测；风险：宏冲突/执行器复杂/重训不稳定 → 失败即 env=0 回滚。

## 4. 治理（Lead 决定）

- **D2=B**：同代码时间窗 A/B；旧对照臂非同代，只作次级参照（报告标注）；不再声称"学习效率 2× 终点"；
- **D3**：近期目标 M1（稳定胜 Lunatic COM，≥90% 非 timeout）+ M3（行为基线四项）；M2/M4 作为后续只读里程碑；
- **D4 暂缓**：不加 actors/GPU；吞吐维持现状，靠优化/记忆/残差提效。

## 5. 可行性判定（冷静）

- **Gen-1 = 高可行**：全部是机械改动+新增小分支；迁移可逆；2–3 人日可闭环；
- **Gen-2 = 有条件可行**：动作残差是唯一能解 ~12× 压缩的路径，但执行器改造+重训风险高；先单角色、env 可回滚；5–8 人日，失败则回退并转"纯优化+奖励"路线；
- **超人 = 当前不可行**：即使 Gen-1/2 成功，也最多到"人类中上/稳定胜 Lunatic COM"；真超人需 Gen-3 记忆/前瞻 + 算力扩张（暂缓）+ 绝对强度标尺；
- **数据量已足够**，瓶颈在抽象层与优化，不在训练时长。
