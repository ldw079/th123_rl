# 数据分发边界 (DATA POLICY)

一句话版: **训练数据不在本仓库分发**。

| 类别 | 位置 | 是否入库 | 说明 |
|---|---|---|---|
| BC 对局语料(replay 衍生) | `data/`(gitignore) | 否 | 含游戏对局衍生数据, 不公开分发 |
| 模型权重/快照 | `data/` `D:\temp\th123_models\` | 否 | 同上 |
| 神谕分片/转储帧 | `data/oracle/` `frames/`(gitignore) | 否 | 同上 |
| 帧数据表(action_tables/reach_maps/card_tables 等) | 仓库内 | 是 | 社区公开**事实数据**的整理产物(帧数/动作 ID/射程), 来源标注见文档; 非游戏资产 |
| 游戏本体/mod 二进制 | 仓库外 | 否 | 东方非想天则版权归黄昏フロンティア; mod 与游戏 exe 不经本仓库分发 |
| 工程产物(评估 JSON/战报) | 仓库内 | 是 | 自产工程数据, 无第三方版权问题 |

公开仓库的访客可合法使用: 代码(MIT)、文档(CC BY 4.0)、
帧数据事实表(随代码 MIT)。
