# CE-0 三项前置探针报告 — 2026-10-15

> 方案: docs/_plans/capability_extension_plan_2026-10-15.md §CE-0。
> 方法: 本轮全部亲验（读源/分片重放/XML解析）。

## 1. 自打逐帧日志开关设计（CE-6/CE-3 前提）

**格式定稿**: 每局一个 npz（`ep_frame_{char}_{actor}_{ep}_{ts}.npz`），内含:
- `left` / `right` (N, 12) uint16/float32: HP/spirit/action/pose/x/y/dir
- `objs_raw` (variable): 逐帧原始 17B 元组列表（type 不可分桶 → 保原始）
- `macro_ids` (M,) int64 + `macro_frames` (M,) int32: 决策序列+决策帧号
- `weather` (N, 3) uint16

**体积估算**: ~2000 帧/局 × ~120B ≈ 250KB/局（含 objs 时 ~400KB）。
滚动保留最近 N=500 局（~200MB，D 盘纪律内——今天的教训: BC 重建 26GB/次，
500MB 自打日志占比 <2%）。

**开关设计**: 环境变量 `TH123_FRAME_LOG=1`（默认关）; fleet 抽样
`TH123_FRAME_LOG_EVERY=20`（每 actor 每 20 局存 1 局）。
写盘走 episode_core 原子写(tmp+replace)。

**未实施**: 本轮仅定稿格式，实施挂起（用户裁定"再观察几天"优先）。

## 2. XML 位移可用性（CE-3 路径判定）

**结论: XML 无自身位移字段 → CE-3 走纯统计法（预期内，不影响成立）。**

证据（suika.xml 3.6MB 全量标签分析）:
- `<move>` 标签属性仅 `id/index/loop/movelock/actionlock` — 无位置
- `<effect>` 标签有 `xspeed/yspeed` — 但是**弹幕特效的速度**，
  不是角色自身位移
- `<clone>` 标签仅 `id/target` — 无位移参数
- 全文搜索 `dx=/dy=/velocity/pushback/selfmove` 零命中
- `<collision>` 只有 `box` (left/up/right/down 判定框)

R24 当年只取了 `hit.box`（射程），因为 movepattern XML 本身就是
**判定/动画/属性**数据，不含角色运动学。角色位移是引擎运行时状态，
只在游戏内存/录制数据（oracle 分片）中可观测。

## 3. objs type 字节语义（CE-2 分桶判定）

**结论: type 无法分桶 → CE-2 降级为"实体计数+最近距离"无类型版。**

证据（60 分片 × 23692 采样帧 × 三主力对手）:
- **首字节 (signed char)**: 值域仅 {-1, +1} — 确认是**朝向标志**而非
  类型（soku_client2.py objs 解析 `'<b2f4H'` 的 `b` 字段）
- **field[3] (unsigned short)**: 18 个唯一值 — 是 **image ID**（弹幕
  贴图编号），不是类型语义; 但可用作**弹型指纹**（区分萃香 C 弹 vs
  B 弹 vs 地雷等，间接类型代理）
- **field[4]**: 值域 {0..7} — 疑似弹幕动画帧号或 ID 子字段（同一 img
  的 f4 值 {0,1,2,3} 共存 → 不是类型）
- **field[5]**: 99% 为 0 — 无信息
- **field[6]**: 高频值如 187/273/317/218/319 — 语义不明（可能是内部
  状态标记; 萃香 22B 地雷 img=853 有明显不同行为: 速度 3.8 vs 其他
  0.0-0.1，寿命短 197 帧 vs 其他上万帧 → **行为特征可区分**，但字段
  本身无显式类型语义）

**降级方案（CE-2 修订）**:
- 弃"类型分桶"路线
- 改走**行为特征分类**: 弹速/寿命/位置聚合度 → 三桶
  （飞行弹: 速度>0.5 + 寿命短 / 设置物: 速度<0.1 + 寿命>200 + 位置
  固定 / 随从实体: 速度中等 + 距对手近 + 寿命中等）
- 保留"实体计数+最近距离"为最小可交付版

**CE-0.1 修正**: 自打日志的 objs 保存原始 17B 元组（不做类型假设，
解析延后到消费端），与降级方案一致。
