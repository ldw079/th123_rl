# 可行性反思 v3：现有架构与"超人教学模型"目标（证据视角）

> 日期: 2026-10-06 晚 · 性质: 第三次目标可行性评估（前两次: goal_feasibility_superhuman_2026-10-04 "六天花板"、2026-10-05 晨 "架构基本配得上"）——本次基于 24 轮审查 + 两次从零审计 + R62 修复核验后的全量证据
> 核心命题: **架构的账已经付得差不多了, 证据的账还没开始还**

---

## 0. 结论（三层, 校准过的）

1. **架构不再是否决项**: 六个天花板实质拆解四个半; 技法三缺口（感知✓/执行件✓机制面/时序◐）。剩余缺口全部是"没跑够/没做完", 没有一个是"想不到怎么做"。
2. **但"足以做到"需要证据而非清单**: 当前证据链定位 = 模型处初学者人类水平（Easy COM 65-80%→Normal 爬升中）、教学层是三个离线函数、规模路径零生产小时。到"挑战顶尖人类资格"保守还需 fleet 稳定运行 4-8 周 + 学习动力学多轮迭代 + 强人类标尺实测; 到"超人"在此之上仍有研究级未知风险——**这部分与两周前评估相同, 架构升级买不掉**。
3. 瓶颈已经从"架构配不配"转移到**"证据够不够"**。

## 1. 现状盘点（只计已验证的实物, 非计划）

### 超人竞技——架构就绪 ~80%, 证据就绪 ~5%

| 组件 | 架构 | 实战证据 |
|---|---|---|
| 自对弈+池+league | ✅ 全备（动态池/加权/20角色） | **league 零运行**; 三角色生态失衡（suika 碾压）未在多角色下验证 |
| fleet 规模化 | ✅ 代码级清零（两轮从零审计+R62） | **零生产小时**（snap 冻于 10-05 16:20 v17）; 本地吞吐上限（2-5×）未实测 |
| 感知 | ✅ 完整（完美状态包+pose/段位/近远A+316维+32 项行为测试） | 刚落地, 对行为的影响未观察 |
| 动作/时序 | ◐ 门语法全备（branch/link/ender 测试绿） | **真实对局零局**（从零#2 前训练侧不可用）; 反应表仍固定权重随机（B2 未做）; 策略本体受宏节奏约束 |
| 学习算法 | ✅ PPO 数学双次机器对账; 真 ratio; 一步等价钉死 | ~1000 更新/角色全部历史; **从未与强人类交手测量** |
| 奖励 | ◐ 势函数+事件+19 项属性测试 | 对齐性未证明只被监控（塑形>胜负退化实证过一次） |

### 教学能力——架构 ~30%, 实体 ~零

- offline 三件（讲解/难度/习惯）测试真值（R62 后）; **核心杠杆 E1 分支演示曾为死代码、重写后零运行**; E5 习惯→惩罚无游戏侧集成; F6 评估矩阵曾恒产 0-0 假战报。
- **完成度 <10% 是诚实数字**: 当前是三个能跑的离线函数, 不是产品。

## 2. 三个结构性隐忧（比缺陷清单更重要）

### 2.1 交付质量税
从零 #2 的 3 P0 + 8 P1 全部是"单元测试绿、集成缝断"型——名义速率虚增: 一晚交付两周工作量, 其中 eval_matrix/branch_demo/teach-价值/ender 接线当时全是死的。R62 修复循环是模范的, 但"冲刺→从零审计→修复"循环本身有成本。**有效速率 = 名义速率 × 存活率, 存活率目前 ~60-70%。** 制度对策已立（集成测试强制条款）, 但其长期存活率待观察。

### 2.2 证据链单点依赖
"模型在变强"的全部证据来自训练日志的 matchup 行与 COM 阶梯——**评估矩阵工具（本该是 380 matchup 独立标尺）从未工作过**。对模型水平的全部认知依赖被评估对象自己产生的数据。教学层与超人标尺都压在这条独立证据链上——它现在是空的。

### 2.3 未知的未知集中于学习动力学
架构组件均为标准件第一版。真正不确定性: league 多角色生态固化风险（suika 型失衡 × 加速样本流）、反应学习化的功劳归属、奖励对齐在强敌压力下的漂移、~1000 更新处的平台期是否架构性。**这些只有跑起来才能回答——而项目最大未偿债务恰是"跑起来"。**

## 4. 第一优先（不是任何新架构, 是三件"变证据为实"）

1. **fleet 点火跑满 48h**（M1）——规模路径从零小时开始计时; 兼收 league 首跑数据;
2. **评估矩阵实测产出第一份真实全矩阵战报**（F6 从占位变实物）——独立证据链开张, 亦是教学层地基;
3. **反应表学习化**（B2）——时序层从"规则随机"升为"策略条件化"的临门一脚。

三件事之后, 下一次反思（M4, 按主规划第 8 周）才有资格用数据回答"超人距离"。

## 5. 风险声明的最后校准

- **不随架构改善而消失的风险**: 格斗自对弈超人无公开先例（研究级）; 本地算力上限（撤云裁定后确定, 触发重议条款在主规划风险表）。
- **随运行可消解的风险**: league 生态、反应学习化语义、奖励对齐、吞吐实测。
- **随制度可压制的风险**: 交付质量税（集成测试条款 + 从零审计周期制——已立, 待观察存活率）。
