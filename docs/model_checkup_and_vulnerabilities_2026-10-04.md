## 2. 结论：现有模型能否达成目标

**不能，且距离可量化**:

| 目标维度 | 现状（实证） | 缺口 |
|---|---|---|
| 超人（胜 Lunatic COM/顶级人类） | 改难度前对 Lunatic COM 8%；三家被动防御型打法 | 算力 2~3 个数量级 + 六天花板（另档） |
| 完成所有高手操作 | 执行类覆盖 ~50-60%；反应类 35 项 **0 项**可达 | 时序墙/感知盲/执行件（另档） |
| 教学性 | 零构件 | 需新建一层 |
| **当前模型自身的健康** | LR 三家钉底、立防 23-34%、卡系统三重死、原子宏 0%、BC 锚与策略拉锯 | **即便不谈超人，当前学习动态也有 5 个待治病灶** |

## 4. 当前模型作为对手的可利用面（"漏洞"的第三义）

人类高手对现有模型的可稳定 exploit 手段（由 §1/§2 病理直接推出）:

1. **中下/蓄力择几乎全中**——模型看不见招式段位与蓄力状态（//128 同桶、pose 零消费）;
2. **投择**——立防 23-34% + 无投掷反制时序（防御硬直后 10F 投掷无敌窗不可达）;
3. **削灵破防循环**——被动防御耗灵，灵尽破防 50F 硬直随意追击;
4. **心理读反向利用**——对手画像是一阶 EMA，识破后可故意喂习惯再反打（攻略"骗"族技法全数生效）;
