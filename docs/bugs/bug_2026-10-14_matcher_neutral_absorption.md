# Bug: 纯按钮宏吞方向变体 — 平局裁决缺特异性优先(未修, P1)

- **发现**: 2026-10-14 rep→宏映射专项审计(与掩码极性独立, 极性修复后
  仍在)。
- **症状**: 纯按钮宏(5B=纯B×10)的 H/V 双 wild 掩码使**带方向的同键
  变体**(2B/6B/j2B 输入流)在 5B 模板上同样得 1.00 分; 2B 自身模板也
  1.00(若极性已修) — 平局裁决只比长度再隐含库序, **特异性低的宏可能
  系统性夺标**(实证: 2B 流 → 5B)。
- **根因**: `_match_all_dp` 平局裁决为 `(score, 更长)` — 缺"约束位数
  (specificity)"维度; 中性模板约束少反而易满分, 长度/库序任意归属。
- **引入**: v3 设计(在途)。
- **影响面**: 方向变体决策点的标签系统性偏向中性宏(5B/5C/A 系)。
- **修复与验证**: 未修。修法: 平局先比约束帧×位总数(更具体者胜),
  再比长度。验证: 2B/6B/j2B 流断言命中各自宏而非 5B。
- **防复发**: 与极性 bug 共用对抗性测试集。
- **状态**: 未修。
