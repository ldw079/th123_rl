# Bug: kit 导出文件名 strftime 双 %% — 恒定名互相覆盖(未修, P2)

- **发现**: 2026-10-13 dist 采集包专项审计, 实跑实证。
- **症状**: `export_helper.py`(kit 根):
  `time.strftime('match_data_%%Y%%m%%d_%%H%%M%%S.zip')` — strftime 里
  `%%` 是字面百分号, 实跑输出**字面量** `match_data_%Y%m%d_%H%M%S.zip`:
  文件名恒定, 每次导出覆盖上一次 → **跨会话采集数据丢失**。
- **根因**: 格式串误写双 %(疑从 % 格式化上下文复制)。
- **引入**: 40cf85b(kit 构建)。
- **影响面**: 仅数据导出环节; 单次会话内导出不受影响。
- **修复与验证**: 未修。修法: `%%`→`%`; 验证: 连续两次导出文件名不同。
- **防复发**: export 后 `os.path.exists` 断言文件名含日期; 或导出走
  已有会话产物命名约定。
- **状态**: 未修。
