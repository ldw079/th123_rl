# Bug: fleet 重启耗尽=静默永久减员(未修, P0)

- **发现**: 2026-10-14 从零#4 分片C(日志实证)。
- **症状**: fleet_supervisor.py:506-508 — MAX_RESTARTS 耗尽仅 `del
  actors[key]`, 无告警、无暂停账本(与 R75 CPU 暂停不对称)。日志实证:
  10-14 16:12 起 marisa actor 因 BC 宽度 assert 连环崩(code=1),
  16:13:53 耗尽放弃 → 车队缺 marisa **1.6 小时无显眼告警**(17:54 人工
  重启)。
- **根因**: 重启预算语义只有"冷却+上限", 没有"耗尽=事故"的升级路径。
- **影响面**: 任何持续崩溃(如代际迁移期)都会变成静默容量损失;
  learner 饿死、A/B 断流。
- **修复与验证**: 未修。修法: 耗尽时监督日志打 ALERT 级行+心跳文件
  置异常标记(或 supervisor 主循环告警节流打印); 恢复路径=人工。
  验证: 模拟连续 exit=1 断言 ALERT 行出现。
- **防复发**: fleet 状态仪表(audit_all)加"车队编制 vs 应有编制"对账。
